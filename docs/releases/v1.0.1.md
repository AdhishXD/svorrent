# Svorrent v1.0.1

This release updates the desktop packages to the current Downloads, playback-readiness, and network UI.

## Changes since v1.0.0

- Downloads now shows the primary video filename, a readable progress bar, clear Pause/Play controls, and a buffering state. Impossible negative per-file percentages are no longer shown.
- The peer inspector displays complete addresses and client details without crowding seven columns into a narrow drawer. Swarm and network views have improved table layout and scrolling.
- Playback readiness now estimates how long more buffering may take at the current download speed. This is an estimate, not a guarantee of uninterrupted playback.
- Includes the Windows startup fix, download recovery improvements, and local API/path hardening added since v1.0.0.

## Compatibility and verification

- Windows packages target x64. The macOS DMG targets Apple Silicon (arm64) only; it is not a universal/Intel build.
- Node.js 18 or newer is required and is not bundled. The macOS app is unsigned and not notarized.
- Frontend and backend tests passed. The DMG checksum and portable ZIP integrity were verified. Windows binaries were cross-compiled on macOS, not runtime-tested on Windows.
